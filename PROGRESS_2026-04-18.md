# Widget Foundation — 2026-04-18

Six-hour plan to land widget primitives (ScrollState, TextBuffer, TextArea, selection highlights) + headless snapshot testing in the Python SDK. All work sits **above** the PGAP protocol and survives the `PlexiApp` → `HostModel` cutover untouched.

**Why this, why now:** text-editor and file-explorer (as Plexi apps) both need a reusable text widget with scroll + selection. Building them in the SDK first means every future app that touches text reuses the same primitives. Headless snapshot testing eliminates the GUI loop from widget development.

**Sequence discipline:** do not start the `PlexiApp` cutover today. The cutover is 2–3 days of focused work; starting with 6 hours on the clock produces half-refactors. Widget work sits above the protocol and compounds regardless of cutover order.
