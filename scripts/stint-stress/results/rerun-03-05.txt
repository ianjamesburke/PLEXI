===== commands related to recovery =====
Git-tracked sprint planning and task tracking

Usage: stint [COMMAND]

Commands:
  init         Create a .stint workspace in the current directory
  add          Create a new task and open $EDITOR for the body
  list         List tasks, optionally filtered
  show         Print a full task (frontmatter + body)
  edit         Open a task file in $EDITOR
  set          Update an existing task's metadata or body without opening $EDITOR
  remove       Remove one or more task files
  claim        Mark a task in-progress. Without an ID, claims the top ready task (lock-protected)
  unclaim      Revert an in-progress task to todo, clearing started_at (inverse of claim)
  done         Mark a task done and optionally record actual time
  log          Add time to a task's actual field (accumulates)
  archive      Set a task's status to archived
  next         Show the next claimable tasks, derived from blockers, sprint order, and area conflicts
  ready        Promote backlog tasks to todo (move out of icebox into the ready pool)
  defer        Send todo tasks back to backlog (move into icebox)
  sprint       Sprint management sub-commands
  check        Validate the task graph, or one task by ID; exit 1 if errors are found
  status       Show a summary: open tasks, blocked tasks, current sprint progress
  update       Update stint from crates.io through cargo install
  completions  Print shell completion script to stdout
  help         Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
