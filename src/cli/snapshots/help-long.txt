Plexi — the last app you'll ever need

Usage: plexi [OPTIONS] [COMMAND]

Arguments:
  [WORKSPACE_PATH]       Open a workspace directory (plexi <path>)

Options:
  -h, --help             Print help
  -V, --version          Print version

Workspace:
  run           Run a named command from commands.toml or a global script
  workspace     Set up a .plexi/ workspace in your project folder
  secret        Store and retrieve secrets (API keys, passwords, tokens)
  agent         Report agent status and install status hooks
  context       Manage the active context (folder and project scope)

Plugins:
  plugin        Open, install, list, scaffold and inspect plugins
  view          Discover, open, and render plugin views
  registry      Watch installed CLI tools for command and option changes
  events        Subscribe to plugin event streams

Panes:
  open          Open a file or directory in the Plexi view that handles it
  file          Open files in Plexi
  pane          List, focus, send input to and capture panes
  notify        Send a notification to the Plexi UI

AI:
  ai            AI diagnostics: hardware scan, integrations, model picks
  needs-you     List everything waiting on you
  permissions   List and change decisions stored by the permission monitor

System:
  experiments   List, enable or disable experiments
  skill         Install the agent skill compiled into this binary
  completions   Print a shell completion script to stdout
  cli           Install the CLI launcher, completions and PATH entry
  host          Start, stop or check a Plexi host from the CLI
  lease         Acquire capacity before starting work (paused: exit 2)
  config        Check your Plexi config file for errors
  note          Capture, list, read, open, and delete notes
  doctor        Audit all installed plugins for capability and config gaps
  debug         Inspect what the host recorded: per-session flight traces
  demo          Interactive keybinding tutorial
  update        Update this channel's package or restore the previous one
  uninstall     Remove this channel's recorded package and launchers

Get started: plexi host start | Docs: https://plexiapp.com/docs
