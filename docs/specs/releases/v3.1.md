## Release-level human verification

Run after all milestone PRs are merged and individually verified.

- [ ] Open every existing app one by one. Each renders identical to pre-v3.1 (visual diff, not just absence of crash).
- [ ] Create a 4-deep nested split. Geometry stays correct at every nesting level — no overlap, no gaps, no visual drift on parent resize.
- [ ] In a Scrollable container, scroll a long buffer past 10k lines. Clipping is exact at the bounds; no overdraw outside the paint region.
- [ ] Force-kill an app process externally (`kill -9 <pid>`). Pane shows red `crashed` lifecycle pill within 1s, click pill to reveal stderr — host stays alive. *(Restart affordance was scoped out of #316; tracked as a separate issue if needed.)*
- [ ] Force-OOM an app (synthetic, e.g. an app that allocates in a loop until SIGKILL). Lifecycle pill turns red within 2s with stderr OOM message visible.
- [ ] Resize a pane while a TextInput inside it has focus (use `backlog` app + `n` shortcut). Cursor stays positioned correctly; layout reflows; no input loss.
- [ ] *(Item dropped — "geometry-test app" was scoped out of #317; the work landed as a renderer signature refactor instead. No standalone debug app exists. Geometry correctness is implicitly verified by item 2 above.)*
