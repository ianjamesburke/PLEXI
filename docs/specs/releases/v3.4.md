## Release-level human verification

- [ ] Plug in an audio interface. Run `plexi devices audio` (or equivalent). All inputs and outputs enumerate with stable IDs.
- [ ] Run a Plexi audio test app. Speak into the mic. App receives PCM frames; log shows frame timestamps and sample rate.
- [ ] Connect a MIDI controller. Run `plexi devices midi`. Inputs and outputs enumerate.
- [ ] Run a MIDI test app. Press a key on the controller. App logs the NoteOn event with correct channel + velocity.
- [ ] Same MIDI app sends NoteOn/NoteOff to a connected hardware synth (Take 5 or equivalent). Synth produces sound.
- [ ] Send MIDI clock from a Plexi app to an external sequencer. Sequencer locks to clock.
- [ ] Open an MP4 in a video pane. Decodes via AVFoundation, plays smoothly at native frame rate. No audio/video desync.
- [ ] Run the GUI↔terminal media bridge demo: terminal plays an audio file, the canvas pane visualizes the waveform in real time.
- [ ] Capability gate: an app without `audio.in` capability tries to capture. Denied, error in-pane.
- [ ] Same for `midi.out` capability.
- [ ] Stress: open 4 audio apps simultaneously. No glitching, no priority inversion, no host-side audio thread blocking.
