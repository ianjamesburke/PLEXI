# plexi-sdk

Python SDK v3 for building Plexi apps running through native `ProcessApp`.

- **Build an app:** [`AUTHORING.md`](AUTHORING.md) — the canonical authoring guide.
- **API reference:** [`../../website/src/content/docs/sdk.md`](../../website/src/content/docs/sdk.md) — every effect, event, and component, generated from the SDK source.
- **Design/protocol spec:** [`SDK_V3.md`](SDK_V3.md).

## Install for SDK development

```sh
uv pip install -e ./sdk/python
```

Changes to `sdk/python/plexi_sdk/` take effect immediately.
