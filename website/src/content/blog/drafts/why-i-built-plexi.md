I built Plexi because I wanted my computer to feel like mine again.

Every app is someone else's idea of what you should be allowed to do. A good app makes the common path obvious. But it also decides where that path ends.

The command line gives you less of a head start. Once you get used to it, though, the appeal is hard to unsee: information and action live in the same place. You ask for something, inspect the answer, and act on it.

That is the part I care about.

## Text is not enough

I love the terminal. I also think terminal people lie to themselves a little.

Text is enough a lot of the time. It is fast, searchable, and scriptable. But graphs are better when you can see them. Forms are easier when the fields are right there. Some tasks deserve a small interface.

I wanted to keep the freedom of the shell and give those interfaces somewhere to live.

[Plexi](/) has terminal panes, project contexts, and [local apps](/docs/apps) that run beside them. A calculator. A todo list. A file viewer. A tiny app an agent writes for one workflow and you keep because it fits how you think.

They should just open.

## Agents changed what I could build

AI changed how I build software. It also made the distance between the pieces harder to ignore. The agent was in one pane, the logs somewhere else, the notes in another app.

I wanted to pull that work into one surface. An agent can help write an app. The app can run beside the terminal. I can inspect the files, run tests, and decide what happens next.

The [host CLI](/docs/cli) gives agents a way to work with that space. The terminal still runs the tools I choose, with their own provider credentials. I can change agents without changing where I keep the work.

## The best app for vibecoding should fit you

That is my standard for Plexi. I want a place where I can build the tool I wish existed, then keep using it right there.

I use Plexi every day, and I am building it in public. Parts are rough. I want feedback while it still has the shape of the thing I meant to build.

[Download it](/download) and follow the [first-session guide](/docs/getting-started). Open one project, split a pane, and run the agent you already use. Start with the work you actually have.
