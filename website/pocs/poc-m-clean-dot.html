Three pane types. One protocol.

Apps run as isolated processes that speak PGAP — newline-delimited JSON over stdio. No shared memory, no inherited file descriptors, no escape hatches. Sandboxed by default, capable by declaration.

01 / terminal

Terminal panes

PTY-backed, vt100-compliant. Every shell you already use. Split horizontal, vertical, zoom, focus — same muscle memory as tmux, faster boot.

02 / app

App panes

External processes speaking PGAP. Python, Rust, anything that can write a JSON line. Capabilities declared in manifest.toml, prompted at runtime, persisted per-workspace.

03 / agent

Agent panes

Plexi IQ — Claude or Codex backends, ledgered turns, full transcript, streams to channel. The agent that builds your apps lives in the next pane over.

An app is fifteen lines of Python.

PGAP is the boundary. Apps emit DrawCommand, receive PlexiEvent. Capabilities up front, secrets scoped to the workspace, no GUI framework to learn — just stdio.

spotify_controller.pyplexi-sdk · python
from __future__ import annotations
from plexi_sdk import App, Frame, Key

def render(frame: Frame, state: dict) -> None:
    frame.title("Spotify")
    frame.row("Now playing", state["track"])
    frame.row("Volume", f"{state['vol']}%")
    frame.hint("⌘P play · ⌘N next · ⌘← prev")

def on_key(key: Key, state: dict) -> None:
    if key == "cmd+p": state["action"] = "toggle"
    if key == "cmd+n": state["action"] = "next"

App(render=render, on_key=on_key).run()
