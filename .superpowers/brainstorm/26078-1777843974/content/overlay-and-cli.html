Two Questions, One Screen

Overlay scope + the Plexi CLI as universal app launcher

Overlay scope
A

Full-window overlay

Floats above the entire Plexi window — all splits, all panes. One z-layer above the tiling grid. Backdrop covers everything. Raycast / Spotlight pattern.

┌─────────────────────────┐
│ ╔═══ file-explorer ══╗ │
│ ║ ~/Documents ║ │
│░░║ clip.mp4 ║░│
│░░║ sample.wav ← ║░│
│░░╚═══════════════════╝░│
└─────────────────────────┘
░ = backdrop (dimmed) below
B

Per-pane overlay

Floats above just the triggering pane. Other splits are unaffected. Like a context menu or autocomplete dropdown.

┌───────────┬────────────┐
│ ╔══════╗ │ │
│ ║ file ║ │ terminal │
│ ╚══════╝ │ │
│ terminal │ │
└───────────┴────────────┘
↑ overlay scoped to left half only
Recommendation: A, always. File explorer, quick note, any launcher — full-window. Per-pane popovers (autocomplete, context menus) are a separate future primitive with different mechanics. Don't conflate them.
Three callers, one action
plexi CLI (shell / scripts / Claude Code)
$ plexi open video-player ~/clip.mp4 --seek=2:35
$ plexi open file-explorer ~/Desktop
$ plexi open audio-player ~/sample.wav
→ sends SpawnPane JSON over PLEXI_SOCKET (same socket as plexi notify)
SDK app / AI agent (DrawCommand)
emit.spawn_pane("video-player",
  args=["~/clip.mp4", "--seek=2:35"],
  layout="split_above")
→ DrawCommand::SpawnPane over PGAP protocol
Native host app (AppCommand)
AppCommand::SpawnApp {
  type_id: "video-player",
  args: ["~/clip.mp4", "--seek=2:35"]
}
→ already exists, already used by file browser
All three routes to the same host-side router. plexi open is just a CLI skin over the socket — it's the same protocol as plexi notify (#295, in progress right now). A SpawnPane message type alongside Notify.
The non-developer angle: If plexi open works from any shell, then bash scripts, Claude Code conversations, cron jobs, and Make targets can all open app experiences in Plexi. You don't need to write an SDK app. You just know the type_id and the args convention. That's "Plexi as an OS" from the outside.
