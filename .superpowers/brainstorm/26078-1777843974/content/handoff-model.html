The AI ↔ Human Handoff Loop

SpawnPane + rich args + pipe-back = the complete model for AI spawning interactive sessions and receiving results

The Pattern
🤖
AI emits
SpawnPane(
"file-explorer",
pipe="sel-123",
layout="overlay")
→
🧑
Human uses UI
Navigates,
presses Enter
on a file
📨
App replies
PipeMessage(
"sel-123",
{ path: "…" })
AI receives PipeMessage → continues with the result. No polling. No timeout hacks.
File explorer selection
AI opens overlay
Human picks file
→ PipeMessage: path
AI opens audio player
  at that path
Video at timestamp
SpawnPane(
  "video-player",
  args=["clip.mp4",
    "--seek=2:35"])
Player opens pre-seeked
Text editor at line
SpawnPane(
  "text-editor",
  args=["doc.md",
    "--line=142"])
Editor opens at section

  • Text editor app (new — out of scope now, file issue)
The key insight on AI navigation: The AI doesn't navigate the file explorer UI — it uses pipe-back. AI opens the overlay with a pipe ID, human does the navigation, app sends one structured message back. The AI-human handoff is always this same loop: spawn → interact → reply. Works for file explorer, text editor, any interactive app.
